# Contributing

Thanks for helping improve Codex Usage Bar.

1. Fork the repository and create a focused branch.
2. Keep changes small and never store account data, tokens, or credentials.
3. Run `./scripts/build.sh` before opening a pull request.
4. Describe the macOS and Codex versions used for verification.

Please open an issue before making a large UI or architecture change. The
compact menu layout and privacy boundary are intentional.
